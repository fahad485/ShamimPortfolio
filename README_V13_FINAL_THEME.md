# V13 — Forest Gold Scientific Editorial Theme

This release keeps the existing portfolio content, dashboard architecture, editing/data system, media system, and section presets intact while updating the **public portfolio visual system** to match the approved dark forest-green / warm ivory / muted-gold reference style.

## Visual direction
- Continuous deep forest-green scientific canvas.
- Supplied green/gold DNA + molecular background used across the public portfolio.
- No decorative leaf silhouettes.
- Gold editorial borders, dividers, buttons and accents.
- Ivory research/about/education/publication cards for strong readability.
- Premium split hero with gold-framed portrait and location badge.
- Dark scientific Skills panel and academic Education timeline.
- Detail pages use the same forest/gold + ivory system.
- Mobile breakpoints preserve contrast, card structure and readable typography.

## Existing functionality preserved
- Dashboard/data architecture and JSON-driven content.
- Existing section layout presets and appearance controls.
- Research project links/detail pages.
- Media/background controls.
- Header language/theme controls and scroll state.
- Existing CV/document assets.

## QA performed
- JavaScript syntax checks: `main.js`, `dashboard.js`, `data.js`.
- JSON parse check for portfolio data files.
- Required background and profile/project assets verified.
- Static page/file integrity verified before packaging.

Note: live GitHub token authentication/publishing cannot be exercised without the user's GitHub credentials/session; no claim of live repository publishing is made from this offline QA environment.
